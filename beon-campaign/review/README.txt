BeOn — حملة من ثلاثة إعلانات / نسخة مراجعة قابلة للتعديل

المواصفات: 1920×1080، 30fps، 600 إطار = 20 ثانية لكل إعلان.
آخر 90 إطارًا ثابتة بصريًا. الموسيقى والمؤثرات أصلية مولّدة حسابيًا، ومرفقة فعلًا.
لا يوجد ملف تعليق صوتي مصري في هذه النسخة. النصوص الحرفية محفوظة في scripts/voiceover.json.
توقيت النص المنطوق لم يُقَس بتسجيل بشري/مولد، ولا يمثل اعتمادًا نهائيًا لسرعة القراءة.

تشغيل:
  npm ci
  npm run dev
افتح الرابط الذي يطبعه Remotion. اختر أحد الإعلانات من الشريط الجانبي.
  npm run lint
  npm run review
أمر review يستخرج صور PNG وفحص بيانات الـCompositions، ولا يصدّر MP4.
المراجعة الآلية تستخدم Chromium في /usr/bin/chromium؛ غيّر browserExecutable في scripts/review.mjs عند الحاجة على جهاز آخر.

المطابقة بين الأسماء المطلوبة وأسماء Studio:
  BeOn_Ownership_20s     → BeOn-Ownership-20s
  BeOn_AfterMessage_20s  → BeOn-AfterMessage-20s
  BeOn_Anywhere_20s      → BeOn-Anywhere-20s
Remotion 4.0.542 لا يسمح بالشرطة السفلية داخل Composition id؛ لذلك استُخدمت الشرطة العادية.

تعديل:
  src/Root.tsx: كل المشاهد وتوقيتاتها مسجلة كعُقد JSX مستقلة، مع ثلاثة إعلانات منفصلة.
  src/scenes/: بداية، رحلة رسالة، عرض منتج، موبايل، وقفلة.
  src/components/: أجهزة، واجهات، بيئة المشهد وعناصر الهوية المشتركة.
  src/brand.ts: لون الهوية ومسارات اللوجو ولقطات الشاشات الحقيقية.
  public/: الأصول المحلية. لا تعتمد المعاينة على روابط خارجية.
  جميع الحركات مرتبطة بـuseCurrentFrame ولا يوجد CSS animation أو توقيت عشوائي.

أصول تحتاج الإكمال قبل النشر:
1. اللوجو الأصلي غير موجود ضمن الملفات المتاحة. لم يُعَد رسمه أو تقليده؛ الرابط beon.chat معروض كنص عادي.
   ضعه في public/brand/logo.png ثم عيّن assets.logo في src/brand.ts. يُعرض كما هو على مساحة بيضاء دون تمديد.
2. صور التطبيق والمتصفح وتسجيلات الاستخدام غير متاحة. الواجهات الحالية تصورات مؤقتة وبياناتها تجريبية.
   ضَع اللقطات في public/screens ثم عيّن assets.browser وassets.mobile. ستُعرض بنسبة أصلية مع objectFit: contain.
   عند إدراجها، راجع مناطق الإبراز ومؤشرات اللمس لتطابق مواضعها في الأصول الحقيقية.
3. لا توجد أصول يد مرخصة، لذا استُخدم جهاز بعمق ومؤشر لمس. لا تظهر يد مرسومة.
4. لم تتوفر المراجع 63410619.mp4 و51786244.mp4 و4714790.mp4. اتُّبع وصف المستخدم لخصائصها دون الادعاء بمشاهدتها.
5. أضف التسجيل المصري المعتمد في public/voiceover ثم غيّر voiceover من Props إلى مساره النسبي، مثال voiceover/ownership.wav.
   music يمكن تعطيله من Props؛ مستواه ينخفض تلقائيًا عند إضافة تعليق.
   اختبر القراءة الطبيعية قبل الاعتماد؛ لا تغير playbackRate لتسريع الكلام.

حدود عرض الإجراءات:
واجهات الموبايل تعرض محادثة توضيحية فقط؛ لا توجد إجراءات تعيين موظف أو إنشاء موعد متابعة داخل التطبيق.
المتصفح يوضح محادثة وبيانات ومسؤولًا، دون الادعاء أنه صورة المنتج الأصلي.
لا يظهر حفظ موعد متابعة لأن أصلًا يثبت هذه العملية لم يُقدَّم.
انتقال الرسالة بين الأجهزة بصري سردي، ولا يثبت مزامنة آنية أو تطابق الخصائص.
لا توجد وعود بنتائج مبيعات أو شراء مكتمل، ولا QR أو روابط متجر مخترعة.
لا أسماء أو هواتف أو محادثات عملاء حقيقيين.
